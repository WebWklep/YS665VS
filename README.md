# YOUR SWEET SIX SIX FIVE

## VISUALISATION STUDIO — Version 0.01

A personal visual production toolkit for image-led motion studies, editorial layouts and catalogue-inspired video experiments.

### First build
- PHOTO TO MOTION: local image upload and live browser preview.
- Motion recipes: Slow Zoom, Ken Burns, Floating Image, Depth Illusion and Still Frame.
- Adjustable duration, zoom and grain.
- Style index and editorial workspace shell.

### Run locally
Open `index.html` in a modern browser. Images are previewed locally in the browser; nothing is uploaded to a server.

### GitHub Pages
In the repository, open **Settings → Pages**. Under **Build and deployment**, choose **Deploy from a branch**, select **main** and **/(root)**, then save. After deployment, the page will be available at the repository's GitHub Pages address.
